# 大件运输弯道通过性检验系统

大件运输弯道通过性检验系统（V1.0）是一款面向大件运输（不可解体物品运输）安全评价的桌面工具。系统依据《公路大件运输安全通行评价技术规范》（JTG/T 2213—2023），采用**多刚体运动学仿真 + 扫掠路径分析（Swept Path Analysis）**方法，对牵引车—挂车—货物组合在圆弧弯道与直角弯道（平面交叉转弯）下的通过性进行检验，输出所需最小弯道半径、最小弯道宽度、外摆值等判定参数，并生成 CAD 风格扫掠工程图与 Word 检验报告。

## 功能特性

- **弯道通过性检验**
  - 圆弧弯道：按附录 B.1.1 / B.1.2 计算转弯通道宽度，计入 0.5 m 安全宽度，校核内缘约束与按公路等级确定的横向预留空间 σ；
  - 直角弯道（平面交叉转弯）：按 5.2.1 条以最内侧转弯半径 R_m、扫空空间最大宽度 W、外摆值 ΔB 三要素判定；
  - 液压轴线挂车：按 B.1.2 闭式解输出扫空参数；**θ 按实际弯道半径反算、La 取轮距、扫空与净空按"仅板车"刚体几何**（依据 B.1.2 条文说明：牵引车基本不增加整体转弯半径）；直角弯按板车计算并对出口叠加牵引车外摆加宽 ΔW₂；
  - 垂直净空校验与平曲线超高路段横向稳定性验算（附录 B.2，含侧滑/侧翻临界速度与停车超高）作为公共校验并入结论；
  - 大件运输尺寸分级（表 3.2.4）与圆曲线查表法（表 4.3.1）作为辅助信息输出。
- **CAD 风格扫掠工程图**：白底纯线框；道路边界黑色粗实线、车辆轮廓蓝色中实线、货物轮廓绿色实线、扫掠包络与半径构造圆弧蓝色细虚线、转弯圆心红色十字，带 R_o / R_i 半径引出线标注；液压车另绘各轴转向轮胎（第六章图式）。
- **Word 检验报告导出**：依据检验结果生成规范格式报告（参数表 + 扫掠图 + 结论文本）；**导出需输入导出口令**（`config.EXPORT_PWD`，默认 `565656`）；结论中"满足/不满足/通过/不通过"逐词着色。
- **模型存档**：检验工况以 `.model`（JSON）格式保存与打开，内置多组示例模型。
- **多账号登录**：内置账号，登录成功后方可进入主界面。

五层架构（ui → model / rendering → core → config）：

```
app/
├── ui/           界面层：登录弹窗、主窗口（左侧三页签输入表单 + 右侧扫掠图与结论）
├── model/        模型持久化：.model（JSON）读写
├── rendering/    渲染层：CAD 风格扫掠工程图（sweep_view）、Word 报告生成（report_assembler）
├── core/         核心计算：
│   ├── datamodel.py    输入数据模型（Pydantic 严格约束）
│   ├── kinematics.py   多刚体运动学仿真（牵引车单车模型 + 挂车铰接约束 + 液压 B.1.2 闭式解）
│   ├── swept_path.py   扫掠包络几何生成与稳态量测（R_o / R_i）
│   ├── passability.py  道路几何构建、转段仿真编排、干涉判定、最小宽度优化
│   ├── transverse.py   路面宽度 / 横向空间宽度（4.2.2 / 4.3.1）
│   ├── grade.py        尺寸分级与查表法
│   └── lateral.py      横向稳定性验算（附录 B.2）
config.py         常量与配置（车型字典、判定常量、登录信息、导出口令等）
main.py           程序入口（修复 Qt 平台插件路径、加载登录与主窗口）
```

## 使用说明

1. **登录**：输入账号密码，通过后进入主界面。
2. **输入工况**：左侧页签分别填写货物、挂车、牵引车参数；道路页签选择弯道类型（圆弧弯道 / 直角弯道），填写道路参数、公路等级、垂直净空与超高。
3. **运行检验**：点击“运行检验”，右侧生成扫掠工程图与通过性结论（通过 / 不通过），并展示各项判定指标。
4. **导出报告**：一键导出 Word 检验报告（需输入导出口令，默认见 `config.py` 的 `EXPORT_PWD`）。
5. **模型存档**：当前工况可保存为 `.model` 文件，之后可打开复用（目录内附示例模型）。

## 判定口径摘要

- **机械挂车（B.1.1）**：转弯通道宽度 = 仿真扫空宽度 R_o − R_i + 0.5 m 安全宽度；
- **液压轴线挂车（B.1.2）**：θ 按**实际弯道半径反算**（tanθ = d/2R，不再固定取结构最大转角）；
  La 取轮距；转弯通道宽度 W_z = 轮迹带 R_外 − R_内 + 0.5 m；扫空空间宽度 W_d = R_max − R_min + σ；
  内/外缘预留的 R_o / R_i 按**仅板车+货物**刚体几何量测（依据 B.1.2 条文说明，**不含牵引车**）；
- **宽度口径**（4.2.2 / 4.3.1，已废止"车道宽 − 2σ"）：路面宽度 = 行车道 + 硬路肩；
  横向空间宽度 = 行车道 + 路缘带 + 硬路肩（划线分隔可借用对向行车道）+ 圆曲线加宽；
- **圆弧弯道通过条件**：查表法（4.3.1-1）命中即满足两项**宽度**判据（转弯通道宽度/扫空空间宽度）；
  但 4.2.1 的内/外缘横向预留 σ 是独立要求，**查表法不豁免**——两条路线都要校核
  外缘净空 ≥ σ 且内缘净空 ≥ σ（净空可为负＝外廓已越出路面边缘）；
  查表未命中时须同时满足 转弯通道宽度 ≤ 路面宽度、扫空空间宽度 ≤ 横向空间宽度、及上述两项 σ；
- **直角弯道**：**所需宽度须同时小于入口与出口**——
  req_w = max(B_t + ΔB, W + ΔW₂)，要求 入口净宽(=入口宽−2σ) ≥ req_w **且** 出口净宽(=出口宽−2σ) ≥ req_w
  （5.2.1；液压轴线挂车的 W/ΔB 按仅板车刚体几何计算，ΔW₂ = 0.5 × 牵引车宽，
  参考文献《道路通过能力》第六章，**进口与出口同样计入**）；机械车包络已含牵引车，ΔW₂ = 0；
- **垂直净空**：车货总高 + 0.1 m 余量 ≤ 净空高度；
- **横向稳定性**：行驶速度 ≤ min(侧滑临界速度 Vch，侧翻临界速度 Vcv)，且满足停车超高条件（附录 B.2）。

    路面宽度；直角弯取 `req_w` 分别对入口净宽与出口净宽），不再出现"查表法"等判定路径字样；
  - 扫掠环带标注只留 `R_o−R_i` 数值（去括注）；不再标注"货物内扫空 $r_s$"（仅保留
    货物前/后外扫空 $R_{sf}$/$R_{sa}$）；
  - 直角弯内角半径标注移到**路面之外**（内角空腔内引出），不再压住路面转角。
- **V1.4.2**：直角弯判定收紧为**入口与出口同时满足**。
  - 判据由「入口 ≥ B_t+ΔB 且 出口 ≥ W+ΔW₂」统一为
    「入口净宽 ≥ req_w **且** 出口净宽 ≥ req_w」，req_w = max(B_t+ΔB, W+ΔW₂)；
    因 `ΔB = max(0, W−B_t)` 且 `B_t ≤ W`，实际 `req_w = W + ΔW₂`；
  - 即 **ΔW₂ 不再只加在出口**：牵引车在进口侧同样可能外摆，故入口也按含 ΔW₂ 的
    所需宽度校核（较规范 5.2.1-1 的 B_r+ΔB 口径更保守）；
  - 效果示例（液压，W≈6.03、ΔW₂=1.25）：入口宽 7.0 / 出口宽 14.0 工况**由"通过"改为"不通过"**；
  - 新增指标 `required_w` / `entry_net_w` / `exit_net_w` / `entry_ok` / `exit_ok` /
    `section_ok` / `lturn_ok`（原 `exit_required_w` 已并入 `required_w`）。
