## 1. 总体流程

一次弯道通过性检验的计算流程如下：

```

输入工况
（货物/挂车/牵引车/道路/速度，经 Pydantic 校验）
        │
        ▼
┌──────────────────────────────────────────────┐
│ 车辆转弯半径换算：δ → r_path                    │
│   r_path = 轴距 / tan δ（受最大转向角约束）          │
└──────────────────────┬───────────────────────┘
        │          ├── ① 圆弧弯道 ──► 稳态圆转量测 R_o / R_i
        │                            扫掠仿真 S(t) 求并 → 扫掠区域
        │                            （液压挂车：闭式解 B.1.2 口径）
        │
        └── ② 直角弯道 ──► 绕角心转 90° 仿真 → R_m / W / ΔB
        │
        ▼
┌──────────────────────────────────────────────┐
│ 三级判定综合（各判据取交集 AND）                    │
│   水平面：扫掠包络 vs 道路几何 + 安全宽度 + 横向预留       │
│   垂直净空：车货总高 + 余量 ≤ 净空                   │
│   横向稳定：V ≤ min(Vch, Vcv) 且 停车超高满足          │
└──────────────────────┬───────────────────────┘
        │
        ▼
  通过性结论（通过 / 不通过）+ 全部判定指标 + 工程图 + Word 报告
```

任一类别不满足即整体“不通过”（`pass_ok` 取各判据之**交集**，即逻辑与 `AND`，非“并集”）。

## 3. 多刚体运动学模型（仿真引擎）

位于 `kinematics.py`，采用**经典铰接单车模型**：牵引车为单车模型，挂车与牵引车在鞍座（第五轮）处铰接，挂车参考点（尾随点）为刚性连杆追逐。

### 3.1 牵引车状态更新

状态点为牵引车后轴中心 $(x, y, θ)$，转向角 $δ$：

- 直线行驶（$|δ| \approx 0$）：
  $$
  x' = x + v\cosθ\,\mathrm{d}t, \qquad y' = y + v\sinθ\,\mathrm{d}t
  $$
- 转向行驶（$|δ| > 0$）：
  $$
  \dotθ = \frac{v\tanδ}{L}, \qquad
  x' = x + v\cosθ\,\mathrm{d}t, \qquad y' = y + v\sinθ\,\mathrm{d}t
  $$
  其中 $L$ 为牵引车轴距，角速率 $\dotθ = v\tanδ/L$。
- 转向角钳制：$δ \leftarrow \mathrm{clamp}(δ, -δ_{max}, +δ_{max})$。

### 3.2 瞬时转弯半径

由单车模型几何关系：
$$
r = \frac{L}{\tan δ}
$$
→ 给定目标半径反算转向角：$δ = \arctan(L / r)$。

### 3.3 挂车"尾随点追逐"约束

挂车尾随点 $(t_x, t_y)$ 与鞍座（kingpin，牵引销）$(k_x, k_y)$ 之间为**刚性连杆**（长度 $L_{loop}$）。无横向滑动约束：尾随点速度等于牵引销速度沿连杆方向上的投影：

1. 连杆方向单位向量 $\hat{u} = (k_x-t_x, k_y-t_y)/\|k-t\|$；
2. 牵引销速度 $(v_x,v_y) = (v\cosθ, v\sinθ)$ 在 $\hat{u}$ 上的投影 $v_{proj} = v_x\hat{u}_x + v_y\hat{u}_y$；
3. 尾随点推进：$t_x += v_{proj}\,\hat{u}_x\,\mathrm{d}t$，$t_y += v_{proj}\,\hat{u}_y\,\mathrm{d}t$；
4. 刚性长度约束重投影：把尾随点重新拉回距鞍座 $L_{loop}$ 处。

> 该模型天然收敛，不会像纯航向积分（$\dotψ = v\sin(θ-ψ)/L_{loop}$）那样在定常转弯中振荡。

### 3.4 整车外轮廓

- 挂车 + 货物合并矩形：以挂车中点为心、长 $=\max(挂车长, 货长)$、宽 $=\max(挂车宽, 货宽)$；
- 牵引车矩形：以牵引车状态点为心、长 $= L + 1$、（宽=牵引车宽）；
- 二者组成 `MultiPolygon`，用于扫掠包络与干涉判定。

### 3.5 仿真剖面（profile）驱动

```
仿真 = [(步数N₁, δ₁), (N₂, δ₂), ...]
```
调用方按"直道入场 → 定转向角转弯 → 切向直道出场"组织剖面，逐帧用 `update_step` 推进，并按 `draw_step` 抽帧采样。

### 3.6 车型/挂车类型说明（V1.2.1 新增）

**（1）类型枚举（`config.py` 与 `datamodel.py::TrailerParams`）**

| 维度 | 字段 | 可选值 | 是否参与判定 |
| --- | --- | --- | --- |
| 挂车类型 | `trailer_type` | 重型机械挂车 / 液压轴线挂车 | **是**（唯一判定依据） |
| 轴线纵列数 | `column_type` | 单纵列 / 2纵列 / 3纵列 / 4纵列 | 否（见 (3)） |
| 转向类型 | `steering_type` | 全轮强制转向 / 自控随动转向 / 锁死轴 | 否（预留字段，见 (4)） |
| 每轴轮胎数 | `TRAILER_TIRE_PER_AXLE` | 机械 4 / 液压 8 | 否（仅绘图层示意） |

**（2）车型在判定中的唯一入口是"液压 vs 非液压"二元区分**

规范 3.2.3 将车辆分为"牵引车+低平板半挂车 / 牵引车+多轴多轮液压悬挂挂车 / 牵引车+特殊组合液压悬挂挂车"三类，但弯道空间可通行性仅对前两类分别给出公式与查表/最大车长/匝道表。本系统以
$$
\texttt{\_is\_hydraulic}(\cdot) = "液压" \in \texttt{trailer\_type}
$$
（`passability.py:75`）对应规范的两套公式：**非液压 → B.1.1**（挂车后轮无助力转向，即铰接尾随模型，天然符合）；**液压 → B.1.2**。这一二元区分即规范所要求的车型差异化口径。

**（3）纵列数 `column_type` 不参与弯道计算**

规范中"纵列数"仅用于 §8 结构/荷载（轴载分级，表8.x）等**力学计算**（规范行 3143-3145：按纵列数、轴线数、轴距、轴长、轮距计算）；B.1.1/B.1.2 的转弯通道宽度、扫空空间宽度公式**不含纵列数**。本系统不涉及承载力学，故 `column_type` 仅作记录不影响判定 **（符合规范）**。

**（4）转向类型 `steering_type` 的适用边界与已消费字段（V1.3.0 更新）**

规范 B.1.2 模型内在地假定"首尾轴**全轮强制转向** + 中间一/两轴**锁死** + 双向转向"（规范行 3627-3633）。故：
- **全轮强制转向**：B.1.2 适用对象 ✅；
- **自控随动转向**：不适用 B.1.2（规范未给该转向方式的弯道公式），本系统按其算法非专门适配；
- **锁死轴**：规范中为 B.1.2 模型的**内置设定**。V1.3.0 起 `hydraulic_turn_radii` **读取** `locked_axles`（D1 双口径）：纯中间锁死不改变首末轴距 $d$（严格守规范）；首/末轴锁死则按 active 首末外推并告警（规范外推）。`axle_max_steering_angle_deg`（D2）同样被消费为 $θ$ 来源。
- **特殊组合液压悬挂挂车**：被规范排除出表3.2.4 分级（行 344）与弯道公式（行 668-672），本系统**不建模**。

因此 `steering_type` 仍为**预留字段、不参与计算**（仅提示能力边界，不作为错误）；`locked_axles`、`axle_max_steering_angle_deg` 已进入 B.1.2 闭式解。

**（5）轨迹来源：非液压走铰接、液压走瞬心刚体；两车型宽度判据口径见 §6/§7**

- **非液压挂车**：绘制轨迹与扫掠区域由 §3 铰接单车模型仿真生成（尾随追逐，B.1.1 天然符合）；
  包络**含牵引车**（B.1.1 条文说明：牵引车与挂车转动中心重合），内外缘净空由该仿真量测的
  $R_o/R_i$ 给出。
- **液压挂车**：B.1.2 闭式解为绕**车辆自身瞬时中心**的刚体圆周。轨迹/扫掠区域按
  `hydraulic_arc_trajectory`（瞬心刚体圆周，D5）生成；宽度判据按 4.3.1 第2款取两条
  独立判据——① 转弯通道宽度 $W_z$（B.1.2-1 轮迹带，$L_a$ 取轮距，≤ 路面宽度）、
  ② 扫空空间宽度 $W_d$（B.1.2-6，≤ 横向空间宽度）。
  **扫掠包络与帧图形只含车板+货物，不并入牵引车**（依据 B.1.2 条文说明：「转弯半径由所
  牵引的液压悬挂挂车决定，牵引车基本不增加车辆整体转弯半径」），故圆弧场景不绘制独立车头；
  内外缘净空（4.2.1）的 $R_o/R_i$ 也同步改为**仅板车刚体几何**解析量测
  （`hydraulic_rigid_sweep_radii`，V1.4.0/D11），与绘图口径一致。
- **直角弯道**：$R_m/W/ΔB$ 按车型分口径——液压仅板车刚体几何（不含牵引车，出口另加牵引车
  外摆加宽 $ΔW_2$），机械走含牵引车的铰接仿真。详见 §7。

## 4. 扫掠路径测量与包络生成

位于 `swept_path.py`。

### 4.1 稳态圆转量测（圆弧弯道）

在固定转向角下绕圆心 $O$ 连续转圈（$\mathrm{turn\_steps} = \lfloor 4\pi/(\dotθ\,\mathrm{d}t)\rfloor$），取整车所有包络点在以 $O$ 为极点的径向距离：

$$
R_o = \max_{t} \max_{p \in \mathcal{E}(t)} \|p - O\|, \qquad
R_i = \min_{t} \min_{p \in \mathcal{E}(t)} \|p - O\|,
$$

其中 $\mathcal{E}(t)$ 为 $t$ 时刻整车包络顶点集。由此得：
$$
W_{swept} = R_o - R_i
$$

### 4.2 扫掠区域生成

把仿真中每帧整车外轮廓多边形**滚动求并**（每 40 帧先局部求并一次，最后整体 `unary_union`），得到扫掠区域：
$$
S = \bigcup_{t} \mathcal{E}(t)
$$
（`polylist_to_multipoly`，可选按容差 `simplify` 简化）。该 $S$ 用于工程图绘制与扫掠判定。

## 5. 圆弧弯道通过性判定

位于 `passability.py::run_arc_scene`，对应规范 **4.3.1 + 附录 B.1**。

### 5.1 车辆实际转弯半径

道路内/外半径 $r_{in} = r_{out} - lane$（$lane$ 为单向行车道宽度，多车道时应传行车道总宽）。车辆沿道路中心线行驶：
$$
r_{target} = \max\!\big(r_{in} + \tfrac{lane}{2},\; 1.0\big),
\qquad δ = \mathrm{clamp}\!\big(\arctan(L/r_{target}),\; -δ_{max}, +δ_{max}\big),
\qquad r_{path} = \frac{L}{\tan δ}.
$$

### 5.2 稳态量测

以圆心 $O$ 稳态圆转量测得 $R_o$、$R_i$：
$$
W_{swept} = R_o - R_i
$$

### 5.3 M1 —— 转弯通道宽度（含安全宽度）

- **机械挂车**（B.1.1-1）：$W_{turn} = W_{swept} + a$，$a = 0.5\,\text{m}$；
- **液压挂车**：$W_{turn} = W_d$（B.1.2-6 整车扫空，含货宽+σ），见 §6——不用轮迹带 $W_z$，避免漏掉超宽货。

### 5.4 判定宽度口径（废止“lane − 2σ”）

规范 4.3.1 第2款要求的是两个**独立**宽度概念，不再做“路面净宽 = 车道 − 2σ”：
- 路面宽度 $W_{road}$：行驶方向行车道 + 硬路肩（`transverse.road_width`）；
- 横向空间宽度 $W_{横}$：按 4.2.2 计入同向路缘带、硬路肩、行车道；划线分隔可借用对向行车道；有圆曲线加宽时含加宽（`transverse.transverse_space_width`）。
- $σ$ 仅用于外缘/内缘与护栏等障碍物之间的预留（M2），与通道宽度解耦。

显式公式（`transverse.py`）：
$$
W_{road} = lane + b_{硬路肩}
$$
$$
W_{横} = lane + b_{路缘带} + b_{硬路肩}
       + (\text{划线分隔? } lane : 0)
       + (\text{有圆曲线加宽? } \Delta_{加宽} : 0)
$$

### 5.5 M2/M3 —— 内/外缘障碍物预留

$$
\Delta_{out} = r_{out} - R_o \quad(\text{外缘净空}), \qquad
\Delta_{in} = R_i - r_{in} \quad(\text{内缘净空})
$$
$$
outer\_ok = \Delta_{out} \ge σ, \qquad inner\_ok = \Delta_{in} \ge σ
$$

### 5.6 验算口径判据（查表未命中时）

$$
width\_ok = W_{turn} \le W_{road} \qquad (\text{① 转弯通道宽度 < 路面宽度})
$$
$$
swept\_ok = W_{swept} \le W_{横} \qquad (\text{② 扫空宽度 < 横向空间宽度})
$$
$$
pass_{verify} = width\_ok \,\land\, swept\_ok \,\land\, outer\_ok \,\land\, inner\_ok
$$

### 5.7 查表优先流程（3.1.2 / 4.3.1）

按表4.3.1 查尺寸级对应的最小半径与最大扫空空间宽度，然后分两条路线：

| 路线 | 触发条件 | 覆盖的判据 | 最终判定 |
| --- | --- | --- | --- |
| 查表法（4.3.1-1） | $r_{in} > $ 表最小半径 **且** $W_{横} > $ 表最大扫空空间宽度 **且** $W_{swept} < W_{横}$ | 仅"宽度"两项（①② 视为满足） | $pass = outer\_ok \land inner\_ok$ |
| 验算法（4.3.1-2） | 上述任一不满足，或该级无表数据（E 级） | ①② | $pass = width\_ok \land swept\_ok \land outer\_ok \land inner\_ok$ |

> **出处说明**：规范 4.3.1 第1款原文为"圆曲线半径**与通行空间宽度**均大于表4.3.1的数值"。
> 其中"通行空间宽度"指横向空间宽度 $W_{横}$（道路可提供的扫空空间），**并非**与扫空宽度
> $W_{swept}$ 比较表值；$W_{swept} < W_{横}$ 是验算口径判据②的补充约束，确保查表命中时扫掠实际
> 仍落在横向空间内。

> **查表法不豁免 4.2.1（V1.4.0 修正）**：查表法（4.3.1-1）只覆盖"转弯通道宽度/扫空空间宽度"
> 这两项**宽度**判据；4.2.1 的横向预留空间 $σ$（车货外廓边缘与护栏等设施/障碍物之间）属
> **"路线"（第4.2节）层面的独立要求**，两条路线都要校核 $outer\_ok$、$inner\_ok$。
> 修正前查表命中会把 ③④ 一并强制置 True，导致"查表法满足"与"内/外缘净空不满足"并存的
> 矛盾结论——车货外廓已越过路面边缘（净空为负）却判通过（示例1 即为该情形）。
> 净空指标 `clearance_outer/inner` 同时**不再 `max(0,·)` 截断**，保留负号以便判断越界量。
> 若某路段路面边缘外确无护栏等障碍物（可借用路肩/对向车道），应显式给定
> `road.lateral_clearance = 0` 放宽该判据。

### 5.8 横向预留空间 σ 取值

显式给定则优先；否则按公路等级（config 4.2.1）：

| 公路等级 | σ (m) |
| --- | --- |
| 高速公路 / 一级公路 / 二级公路 | 0.5 |
| 三级公路 / 四级公路 | 0.25 |

**说明：σ 用于"外缘/内缘与护栏等障碍物之间的预留"判据（§5.5），不再从通道宽度或路面宽度中双侧扣除；"0.5 m 安全宽度"（§5.3）与"横向预留空间 σ"是两个独立项。V1.1 已废弃旧口径 `lane_avail = lane − 2σ`。**

## 6. 液压轴线挂车闭式解（B.1.2）

位于 `kinematics.py::hydraulic_turn_radii`。多轴多轮液压悬挂挂车，中间一轴（或两轴）锁死、
首尾轴全轮强制转向，各轮绕同一瞬时中心做圆周运动。

> **V1.4.0 口径整治（D9/D10/D11）**：① θ 不再固定取结构最大转角，改为**按实际弯道半径
> 反算**（D9）；② B.1.2-3 的 $L_a$ **取轮距**（D10，原暂取 0）；③ 内/外缘 $\sigma$ 预留的
> $R_o/R_i$ 改为**仅板车+货物刚体几何**量测，不并入牵引车（D11）。
> 依据为规范 B.1.2 条文说明：「牵引车+多轴多轮液压悬挂挂车的转弯半径**由所牵引的液压悬挂
> 挂车转弯半径决定**，牵引车因车身较短，转弯角度大，**基本不增加车辆整体转弯半径**」，
> 以及参考文献《道路通过能力》第六章「自走式挂车」模型（该章亦明确牵引车对转弯半径可不予
> 考虑）。**故液压车的圆弧弯道计算不带车头**。

设：$L_{轮挂}$ 为**相邻轴间距**（`axle_spacing`）、$N_a$ 为轴数、
$D_{总}$ 为车板总长（`trailer.length`，不含牛颈/连接杆耦合段）、
$C$ 为动力机组长度（`power_unit_length`，缺省 0 → 无 C）、
$b$ 为轮距（`track_width`）、
$d$ 为首末有效轴距（纯中间锁死时 $= L_{轮挂}(N_a-1)$；首/末轴锁死按 active 首末外推并告警）。

**θ 的取值口径（D9）**——三种来源，优先级由高到低：

| 优先级 | 来源 | 公式 | 说明 |
| --- | --- | --- | --- |
| 1 | 显式传入 `turn_angle_theta` | — | 供测试 / 外部指定 |
| 2 | `actual_turn_radius`（**圆弧弯道默认走这条**） | $θ=\arctan\dfrac{d}{2R}$ | 板车沿半径 $R$ 走行时瞬心偏距即走行半径，故 $base\equiv R$ |
| 3 | 结构最大转角（均未给时） | $θ_{max}=\min(\texttt{axle\_max\_steering\_angle\_deg},\,60°)$ | 固有最不利口径 |

$$
base = \frac{d}{2\tan θ} \qquad \text{（瞬心横向偏距）}
$$

> **为何必须反算**：$base=d/(2\tan θ)$ 在规范口径下**就是板车自身的走行半径**。若固定取
> $θ=θ_{max}$，得到的是"最紧转弯下的固有参数"，$base$ 很小（$d=4.5$、$θ_{max}=45°$ 时仅
> 2.25 m），再按 B.1.2-4 减去车板悬伸 $(D_{总}-d)/2$ 必然为负——说明 B.1.2-4/-5 隐含假设
> "车板长 ≈ 轴组跨度"。按实际半径反算后 $base\equiv R$，$R_{in}$ 恒为正，公式对长车板同样成立。

**扫空空间宽度（车货总体）**

$$
R_{in} = base - \frac{D_{总} - d}{2} \tag{B.1.2-4}
$$
$$
R_{out} = \sqrt{\Big(base + \frac{D_{总} + d}{2}\Big)^2
              + \Big(\frac{L_{轮挂}N_a}{2} + C\Big)^2} \tag{B.1.2-5}
$$
$$
W_d = R_{out} - R_{in} + a, \qquad a = \text{TURN\_SAFE\_CLEARANCE\_B12} = 0.5\,\text{m} \tag{B.1.2-6}
$$

> 说明：B.1.2-4 符号为 **base − (D$_{总}$−d)/2**；B.1.2-5 为**勾股合量**，横项
> $L_{轮挂}N_a/2 + C$。若 B.1.2-4 仍取负（车板过长/轴距过短）则按 0.5 m 下限参与判定并告警；
> 反算口径下通常不再触发。
>
> ⚠ **待复核**：B.1.2-5 的**半径腿** $\big(base+(D_{总}+d)/2\big)$ 混入了纵向长度，与刚体几何
> 真值 $R_o=\sqrt{(R+w/2)^2+(L/2)^2}$ 相差较大（12 m 车板算例：**34.879 m vs 28.636 m**）。
> OCR 版 B.1.2-5 结构无法完全确认，建议对照规范原 PDF 图 B.1.2 复核。$W_d$ 沿用 B.1.2-5
> 属**偏保守**；若改用刚体扫空带 $R_o-R_i$，部分工况结论会由"不通过"转为"通过"。

**转弯通道宽度（轮胎通道）**

$$
R_{内(轮迹)} = base \tag{B.1.2-2}
$$
$$
R_{外(轮迹)} = \sqrt{\big(base + b\big)^2
              + \Big(\frac{L_{轮挂}(N_a-1)}{2}\Big)^2} \tag{B.1.2-3}
$$
$$
W_z = R_{外(轮迹)} - R_{内(轮迹)} + a \tag{B.1.2-1}
$$

> **$L_a$ 取轮距（D10）**：规范 OCR 版未给出 $L_a$ 的符号定义。以参考文献《道路通过能力》
> 第六章"自走式挂车"的最小转弯半径式
> $R_{\min}=\sqrt{(l/\tan\alpha_{\max}+b)^2+l^2}+\dfrac{B-b}{2}$（$l=d/2$，$b$ 轮距，$B$ 车宽）
> 与 B.1.2-3 逐项比对：取 $L_a=b$ 时二者一致（仅差车宽−轮距悬伸项 $(B-b)/2$）。
> 原暂取 $L_a=0$ 会低估 $R_{外(轮迹)}$ 与 $W_z$（**偏不安全**）：12 m 车板 4 轴算例
> $W_z$ 由 1.432 m 修正为 3.486 m。

**内/外缘 $\sigma$ 预留的 $R_o/R_i$（D11，仅板车）**

位于 `kinematics.py::hydraulic_rigid_sweep_radii`。板车绕道路圆心 $O$ 做刚体转动时航向恒
垂直于半径（取切向），车板+货物包络矩形 $(\text{env}_L\times\text{env}_W)$ 上任一点
$P=C+u\hat t+v\hat r$ 满足 $|P|^2=(R+v)^2+u^2$，故

$$
R_o = \sqrt{\Big(R+\frac{\text{env}_W}{2}\Big)^2 + \Big(\frac{\text{env}_L}{2}\Big)^2},
\qquad
R_i = R - \frac{\text{env}_W}{2}
$$
$$
\text{env}_L=\max(\text{车板长},\ \text{货长}),\qquad
\text{env}_W=\max(\text{车板宽},\ \text{货宽})
$$

其中 $R$ 为板车走行半径（圆弧弯道取道路中心线半径 $r_{内}+lane/2$，不受牵引车转向限位约束）。

**圆弧弯道判定口径（液压车）**

| 判据 | 量 | 出处 |
| --- | --- | --- |
| ① 转弯通道宽度 ≤ 路面宽度 | $W_z$（B.1.2-1，含 $L_a=b$） | 4.3.1 第2款 1) |
| ② 扫空空间宽度 ≤ 横向空间宽度 | $W_d$（B.1.2-6） | 4.3.1 第2款 2) |
| ③ 外缘预留 | $R_o$（仅板车刚体几何） | 4.2.1 |
| ④ 内缘预留 | $R_i$（仅板车刚体几何） | 4.2.1 |

轨迹/扫掠仍按 B.1.2 瞬心刚体圆周生成（D5，`hydraulic_arc_trajectory`，包络不含牵引车）；
横向稳定性 B.2 的"最内侧转弯半径"取板车的 $R_i$。

> **未纳入本轮**：直角弯道（5.2.1）液压车仍按含牵引车的仿真实测量测 $R_m/W/\Delta B$
> （`_simulate_right_angle` 传入 `b12` 仅用于轴层绘图）。参考文献第六章建议直交弯道按
> "挂车计算 + 出口加宽 $\Delta W_2\approx$ 牵引车宽$/2$"处理，待后续改造。

## 7. 直角弯道通过性判定（5.2.1）

位于 `passability.py::run_right_angle_scene`，对应规范 **5.2 平面交叉转弯**。

### 7.1 仿真量测

绕角心 $C$ 转 $θ_{turn}$（默认 90°）。入口/出口宽度 $W_{en}$、$W_{turn}$。量测得最内侧半径
$R_m$、最外侧包络半径 $R_{max}$、扫空宽度 $W$：

$$
R_m = R_i, \qquad R_{max} = R_o, \qquad W = W_{swept}
$$

**车型口径（V1.4.0 区分）**：

| 车型 | $R_o/R_i/W$ 来源 | 包络是否含牵引车 |
| --- | --- | --- |
| 牵引车+低平板半挂车（机械） | 铰接尾随仿真绕角心稳态量测 | **含**（B.1.1 条文说明：牵引车与挂车转动中心重合） |
| 牵引车+多轴多轮液压悬挂挂车 | 板车+货物**刚体圆周**解析量测 $R_o=\sqrt{(R_{veh}+\text{env}_W/2)^2+(\text{env}_L/2)^2}$、$R_i=R_{veh}-\text{env}_W/2$ | **不含**（B.1.2 条文说明 + 第六章"自走式挂车"） |

其中 $R_{veh}=\max(W_{en},W_{turn},1.2L_{板},10)$ 为板车走行半径（取该转弯的几何半径，不受牵引车
转向限位约束）；液压车 θ 同样按 $R_{veh}$ 反算（D9）。轨迹/绘图同步只画板车。

### 7.2 三要素计算

- 车货总宽度：$B_t = \max(W_{tr}, W_{cargo})$
- 外摆值：$ΔB = \max(0,\; W - B_t)$ —— **保守近似**（V1.2 注明）：$W$ 为扫空空间最大宽度（含内、外侧甩出），
  $W - B_t$ 会把内摆一并计入，使 $ΔB$ 偏大、判定偏严格；规范严格口径应从扫掠几何单独量取车辆外侧甩出量，本系统暂以该近似并配合查表5.2.1 复核
- 横向预留：$σ$，显式给定优先，否则取 `INTERSECTION_RESERVE`（默认 0.5）
- **牵引车外摆加宽 $ΔW_2$（V1.4.0 新增，V1.4.2 改为进出口同时计入）**：液压车仅按板车
  计算时，牵引车外轮可能落在挂车轨迹线以外，所需宽度需加宽。参考文献《道路通过能力》
  第六章"牵引车对转弯的影响"（$ΔW_2 = d/2 - (R_{\min}-O'Q)$，表6-1 注简化为
  $d/2-0.16$，$d$ = 牵引车宽度），本系统取保守上限：
  $$
  ΔW_2 = \text{TRACTOR\_SWING\_EXIT\_FACTOR} \times W_{tr}
        = 0.5 \times W_{tr} \quad (\text{液压车})
  $$
  机械车包络已含牵引车，$ΔW_2 = 0$，不叠加。

### 7.3 判定公式（5.2.1）

**所需宽度**（入口与出口共用同一量）：

$$
req_w = \max\big(B_t + ΔB,\; W + ΔW_2\big)
\xrightarrow[\;B_t \le W,\; ΔB = \max(0, W-B_t)\;]{}\; W + ΔW_2
$$

右转弯（5.2.1-1/-2，规范两侧均扣 $2σ$）——**入口与出口须同时满足**：
$$
(W_{en} - 2σ) \ge req_w \quad\land\quad (W_{turn} - 2σ) \ge req_w
$$
其中 $W_{en}$ 为进口道总宽，$W_{turn}$ 对应规范"右转处可通行宽度 $W_{rturn}$"（系统以出口宽度近似）。

> **V1.4.2 收紧说明**：规范 5.2.1-1 字面为 $W_{en}-2σ \ge B_r+ΔB$、5.2.1-2 为
> $W_{rturn}-2σ \ge W$，即 $ΔW_2$ 名义上只加在出口。本系统改为**两侧都按含 $ΔW_2$ 的
> $req_w$ 校核**——牵引车在进口侧同样可能外摆，故取更保守口径。因 $ΔB=\max(0,W-B_t)$
> 且车体总宽 $B_t$ 恒 ≤ 扫空宽度 $W$，有 $B_t+ΔB = W$，故这一改动等价于"把 $ΔW_2$ 也加到
> 入口"。效果：液压车 $W\approx6.03$、$ΔW_2=1.25$ 时，入口宽 7.0/出口宽 14.0 的工况
> 由"通过"改为"不通过"。若需回到规范字面口径，把入口判据的右端换回 $B_t+ΔB$ 即可。

左转弯（5.2.1-3/-4，规范两侧均扣 $σ$；V1.1 起严格使用平面交叉物理区可通行宽度 $W_{section}$ 与左转处可通行宽度 $W_{lturn}$）：
$$
(W_{section} - σ) \ge req_w \quad\land\quad (W_{lturn} - σ) \ge req_w
$$

**转向口径（V1.2 注明）**：当前 `pass_ok = right_ok`，最终判定**仅按右转弯取结论**；
左转弯公式与 $W_{section}$/$W_{lturn}$ 供对比与参考（$W_{lturn}$、$W_{section}$ 缺省时回退到入口/出口宽度）。
若需按左转或双向判定，需在界面增设转向方向后由 `left_ok` 主导。所需最小出口转弯带（参考量）：
$$
W_{2,min} = \max(W + ΔW_2,\; B_t + ΔB) + 2σ
$$

> **待复核**：规范 5.2.1 条文说明指出 $R_m/W/ΔB$ 应由"车货总体外廓尺寸、平面交叉角度及
> **路面内缘半径**"计算，且 $R_{in}$ 取 $\max(15\,\text{m}, \text{车辆最小内侧转弯半径})$
> （表5.2.1 按 15/20/30 m 计算，为**最不利情况**）。本系统目前以走行半径 $R_{veh}$ 的刚体
> 几何代替该"最不利"口径，且未接入 $R_{in}\ge 15$ m 的下限，故 $W/ΔB$ 可能偏小（偏不安全），
> 建议后续按 5.2.1 条文说明改造，或按表5.2.1 逐级复核。

## 8. 垂直净空校验（M7）

位于 `passability.py::_vertical_check`。车货总高：
$$
H_{总} = h_{车板} + h_{货}
$$
按净空场景 `clearance_structure_type` 分阈值判定，间隙 $\text{gap} = N_{净空} - H_{总}$：

| 场景 | 判据 | 出处 |
| --- | --- | --- |
| 跨线构造物 / 上跨桥 | 间隙 不宜 <0.10，**不应 <0.05**（4.4.2 竖曲线跨线同） | 6.4.1 / 4.4.2 |
| 隧道 | 顶部距洞顶(含设备) **≥0.20**；侧壁(≥0.50)、检修道(货物底高于检修道≥0.20)、货物底缘(≥0.20) 净空**未纳入本系统**，属隧道空间专项评价 | 9.2.1 |
| 匝道 | 顶部净空按**结构净空通用阈值**：宜 ≥0.10，**不应 <0.05**（6.3.2 的"不宜<0.50/不应<0.25"本是外廓与护栏间**横向预留**，非顶部竖向间隙，**未纳入本系统**，需专项评估） | 6.3.2 + 6.4.1/4.4.2 |

**判定档位**：跨线 ① $gap \ge$ 宜阈值 → 通过（宜满足）；② 应 $\ge gap <$ 宜阈值 → **仍通过**但标注"需采取措施"；

匝道仅两档（$\ge 0.10$ 宜 / $<0.05$ 不应）；隧道单档（$gap \ge 0.20$）；③ $gap <$ 不应阈值 → 不通过。
任一场景不通过即参与最终 `pass_ok` 交集（`gap < 不应阈值` 直接导致整组不通过；V1.1 起不再只做 `H_总+0.1 ≤ N_净空`）。

## 9. 横向稳定性验算（附录 B.2）

位于 `lateral.py`。$r$ 取最内侧转弯半径，$i_h$ 为超高、$b$ 为轮距、$h$ 为重心高、$μ$ 为横向力系数——取衬垫摩擦系数作**保守下限**（衬垫摩擦通常小于路面-轮胎附着，取之偏于安全、判定更严格）。

### 9.1 侧滑临界速度（B.2.2）

$$
V_{ch} = 3.6 \sqrt{\frac{g\,r\,(μ + i_h)}{1 - μ\,i_h}}\ \text{km/h}
$$
（$g = 9.81\,\mathrm{m/s²}$）

### 9.2 侧翻临界速度（B.2.2）

$$
V_{cv} = \sqrt{\frac{127\,r\,(b + 2\,h\,i_h)}{2h - b\,i_h}}\ \text{km/h}
$$

### 9.3 最大稳定速度（B.2.1/B.2.2）

$$
V_{hmax} = \min(V_{ch},\; V_{cv})
$$

### 9.4 停⻋横向稳定性（B.2.3）

$$
i_h < \frac{b}{2h}
$$

### 9.5 通过条件

$$
V_{行驶} \le V_{hmax} \quad\land\quad \text{（停车超高满足）}
$$

## 10. 尺寸分级与查表法（表 3.2.4 / 表 4.3.1）

位于 `grade.py`。

### 10.1 表 3.2.4 分级

由车货总体尺寸分长/宽/高三通道分级（A–E），取最高级：

- **总长度**（低平板半挂车）：A ≤17 m，B (17,22]，C (22,30]，D (30,35]，E >35；
- **总长度**（液压悬挂挂车）：A ≤22，B (22,31]，C (31,41]，D (41,45]，E >45；
- **总宽度**：A (2.55,3.00]，B (3.00,3.50]，C (3.50,3.75]，D (3.75,4.50]，E >4.50（≤2.55 视为非超限取 A）；
- **总高度**：≤4.50 高度维度**不抬级**（A/B/C 由长、宽维度决定），仅跨 4.5 / 5.0 边界抬到 D / E
  （V1.3.0 修正：此前将 (4.00,4.50] 固定记 C，会把长、宽均 A、总高 4.3 m 的车**高估为 C**）。

总长 $=\max(挂车长, 货长) + \text{牵引车车身长}$（表3.2.4 的"总长度"为牵引车+半挂车整车总长，
V1.3.0 补加 `tractor.length`，故比"车板/货长取大"更严格）、
总宽 $=\max(挂车宽, 货宽)$、总高 $= h_{车板}+h_{货}$。

## 11. 道路几何构建

### 11.1 圆弧弯道中心线缓冲

用车辆行驶中心线（入弯直道 + 圆弧 + 出弯直道）做等宽 `LineString.buffer` 得到道路带；不等宽时分段缓冲。道路几何仅用于绘图包住整车姿态，**不参与判定**（判定基于解析半径，见 §5）。

### 11.2 直角弯道 L 形几何

两条正交直道 + 内角导圆：入口道沿 $x=r$ 自 $-Y$ 向 $+Y$，出口道沿 $y=r$ 向 $-X$，内角处以 `corner_radius` 外凸圆弧圆顺，外角为干净直角。
